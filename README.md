## 🏛️ Arquitectura Modular en Disco

```
bai-bai-bake/
├── index.html          # Vista SPA semántica con Tailwind CSS, Hero y Vitrina
├── css/
│   └── styles.css      # Sistema de diseño: grano editorial, scrollbar de lujo y microinteracciones
└── js/
    ├── products.js     # Catálogo sensorial tipado, renderizado dinámico y modal de cata
    ├── cart.js         # Estado reactivo, persistencia en localStorage y enlace a WhatsApp
    └── chatbot.js      # Concierge inteligente "BakeBot" con árbol NLP y transferencia a WhatsApp
```
